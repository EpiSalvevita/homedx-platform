# Meetings

Agendas, notes, and decisions that are not engineering tickets.

## Naming

`YYYY-MM-DD-topic.md` (copy [`_template.md`](_template.md)).

## Tips

- Capture **decisions** and **owners**, not a transcript dump.
- Link out to `work/roadmap/`, `work/strategy/`, or `docs/` when a meeting creates follow-up work.
