# UI-/UX-Hinweise für HomeDX

## Allgemeine Gestaltung

- Pro Bildschirm maximal 1–3 Fragen anzeigen.
- Fortschrittsanzeige: „Schritt 2 von 8“.
- Antwortoptionen groß, touch-freundlich und barrierearm.
- Patiententexte einfach, freundlich und ohne Fachjargon.
- Ärztetexte knapp, fachlich präzise und auswertungsorientiert.
- Speichern/Fortsetzen ermöglichen, besonders bei Bogen B/D.

## Sprache

Patient:innen:

- „Wie lange bestehen Ihre Beschwerden ungefähr?“
- „Sind morgens Gelenke steif?“
- „Wie gut haben Sie das Ergebnis verstanden?“

Ärzt:innen/Rheumanetzwerk:

- „Wie erfolgt aktuell die Abklärung bei Verdacht auf entzündlich-rheumatische Erkrankung?“
- „Welche diagnostischen Engpässe sehen Sie im aktuellen Versorgungspfad?“
- „Welche Evidenz wäre für eine Nutzung von RheumaCheck erforderlich?“

## Sicherheits-/Haftungshinweis

Vor Patient:innenbögen sollte ein kurzer Hinweis stehen:

„Dieser Fragebogen ersetzt keine ärztliche Diagnose. Bei akuten oder starken Beschwerden wenden Sie sich bitte an eine Ärztin oder einen Arzt.“

## Datenschutz-Hinweis

Vor produktiver Nutzung muss geklärt werden, ob personenbezogene Daten gespeichert werden. Für frühe Tests kann ein Demo-/anonymer Modus sinnvoll sein.
