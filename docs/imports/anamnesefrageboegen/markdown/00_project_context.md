# Projektkontext für die Online-Umsetzung

## Ausgangslage

Im RheumaCheck-Projekt sollen Testdaten, Fragebogendaten, Usability-/Begleitforschungsdaten und versorgungsbezogene Informationen so zusammengeführt werden, dass später ein digital nutzbarer Ablauf entsteht.

Die Fragebögen wurden aus der V6.2-Architektur abgeleitet. Die wichtigste Korrektur gegenüber früheren Arbeitsfassungen ist, dass die „Umfrage zur Standardmethode“ nicht nur als Patienten-Ist-Stand-Bogen verstanden werden sollte, sondern als Befragung von Mitgliedern des Rheumanetzwerks bzw. ärztlichen/versorgungsnahen Akteuren.

## Ziel der HomeDX-Integration

Das HomeDX-System soll perspektivisch folgende Dinge ermöglichen:

- digitale Erfassung strukturierter Antworten,
- einfache, barrierearme Nutzerführung,
- getrennte Nutzerflüsse für Patient:innen und Ärzt:innen/Rheumanetzwerk,
- später mögliche Verknüpfung mit Testdaten bzw. CUBE/App-Workflow,
- Export für Begleitforschung und Auswertung,
- Versionierung der Fragebögen.

## Abgrenzung

Die Online-Fragebögen sollen zunächst keine Diagnose stellen. Sie sollen Daten erfassen, strukturieren, für Auswertung/Studie/Begleitforschung verfügbar machen und ggf. spätere Triage- oder Prozessentscheidungen vorbereiten.
